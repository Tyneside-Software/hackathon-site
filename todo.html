How a card ships

  1. The increment is visible on the running site (not a branch of theory).
  2. Home, Map, and Board still load if the new thing is half-finished — fallbacks, never a blank page.
  3. Drag the card to Ready to deploy when someone else can click it without a briefing. The brief on the card is that briefing.
  4. Open the card and move it to Done, or run python scripts/update_board.py done 12 --by michael while the API is up.
  5. A card can move to any column, including back. The backlog is the side pile, off this board.

GitHub loop

Do this on the Tyneside-Software repos, not personal forks unless you have been told otherwise. Full clone-and-run steps live on Onboarding.

  1. Clone (or pull) hackathon-site and hackathon-api as sibling folders.
  2. Run both: .\start.ps1 in the site repo.
  3. Make a tiny visible change. Confirm it still runs.
  4. git add · git commit · git push origin main.
  5. Check the commit on GitHub, then move the card to Done.
